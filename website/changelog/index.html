RELEASE 0.3.9 · 25 AUG 2026

Everything since 2.5.3.

This stable Release rolls the Shard Lab, new alerts, Century Cake tracking, map and UI corrections, compatibility experiments and accumulated fixes into matching Minecraft 26.1.2 and 26.2 builds.

01 / 05

NEW CAPABILITIES

More information, still local.

SHARD LAB

A complete offline Shard workspace

All 320 Bazaar-listed Attribute Shards now have Shard-specific icons, details, effects, family, Skill and acquisition information, direct Recipes and Uses, Fusion Trees, alternative routes, Materials Only and Ironman planning, Fusion Lines and Hunting Box warehouse counts.

ALERTS

Deployables and Century Cakes

Power Orb and Flare despawns can show one center-screen alert with owned audio controls. Century Cake activation and refresh messages start real 48-hour timers, with a cake-icon effects screen, merged expiry notices and a click-only visit link.

FISHING & HUNTING

Timely, bounded cues

The optional Ciallo bite sound handles local water and Hypixel lava hooks once per cast. Hunting additions include Lasso REEL, Beeheemoth, Critterdex, Wumpa, Cold, capture-readiness and ownership-bounded Tree Gift cues.

PROVIDERS

Unified settings and HUD concept tests

Separate, opt-in local scanners can surface recognized settings and HUD controls from installed SkyHanni, Skyblocker, Firmament, BabyZombieAddons and Feesh builds. Refresh is manual and double-confirmed; unreadable controls appear as compatibility gaps.

Concept test — unstable, default-off, use cautiously.

Unified Settings and Unified HUD Editing are not production-stable. Provider updates can invalidate mappings.

02 / 05

REFINED EXPERIENCE

Clearer structure and presentation.

VERSIONING

New public version format

The stable line is now 0.3.9 Release. Playable files use QCloudy_Addition-0.3.9+Minecraft-Release.jar, with one matching sources JAR per target.

UI

Function-first menus

Fishing, Farming, Dungeons, Slayer and other major areas are first-class categories. Empty provider categories hide, secondary cards no longer duplicate their parent, and clickable recipe text gains deliberate hover and underline feedback.

MAPS & HUDS

Approximate when precision would mislead

The Dwarven Mines map uses a continuous real-time X/Z projection and ignores Y. HUDs render only real content, while pet and Shard displays use corrected colours, icons and spacing.

03 / 05

ACCUMULATED CORRECTIONS

The bugs users could actually see.

LIFECYCLES

SOS replacement now resets expiry

Placing a new recognized Flare replaces the old lifecycle immediately. The previous three-minute deadline cannot survive and trigger a stale alert. World changes clear pending state silently.

DETECTION

Fishing, cakes and personal rewards

Lava fishing receives the same one-shot bite path as water fishing without replaying on reel-in. Tree Gifts require bounded ownership evidence. Starborn Century Cake recognizes the real Hunting Fortune wording and private stat glyph.

MENUS

No more blank or duplicated categories

Empty Dungeons and other provider-only categories disappear. Fishing no longer opens into another redundant Fishing layer, and both unified-control master switches remain independently visible under Supported Mods.

RENDERING

Maps, pets and Shards stay aligned

The Park no longer exposes the Mining HUD, Golden Dragon no longer shows a false maximum level, Shard search and recipe layouts keep real hitboxes aligned with text, and navigation highlights the correct section.

04 / 05

REMOVED, NOT HIDDEN

Less legacy surface to maintain.

ITEMS & MENUS

Legacy menu automation

Slot locking, Storage Overlay and menu middle-click conversion were removed from QCA rather than left as hidden switches.

COMMANDS

Two ambiguous aliases

The /aca and /ca settings aliases were removed. Local /qca and /qc remain the supported settings commands.

DEPLOYABLES

Distance-based warnings

Old range-leave and entity-unload interpretations were discarded. Power Orb and Flare alerts now mean one thing only: the tracked deployable fully ended.

05 / 05
