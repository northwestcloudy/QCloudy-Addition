CLIENT-ONLY BOUNDARY

Helpful, not automatic.

QCloudy_Addition reads information already delivered to your Minecraft client and turns it into local UI, maps, HUDs and alerts. It does not play the game for you.

01 / 05

THE LINE QCA WILL NOT CROSS

Information in. Local presentation out.

The mod observes client-visible text, menus, entities and item data. Its own features stop at presentation and player-requested convenience actions.

✓

What QCA does

  • Render local HUDs, maps, outlines and menus
  • Play feature-owned local alert sounds
  • Store local configuration and observed client data
  • Open documented actions after a direct click or command
×

What QCA does not do

  • Move, aim, click, cast, reel, fight or fuse automatically
  • Retry connections or send commands in the background
  • Run its own Bazaar, Wiki, telemetry or update network client
  • Guess unsupported provider settings and write them anyway

02 / 05

LOCAL DATA FLOW

No hidden cloud service.

01

Received by Minecraft

QCA works from text, entities, item stacks and menus that the connected server has already delivered to the client.

02

Processed locally

Matching, timers, layout, route planning and compatibility scans run inside the game process. No cloud AI is required.

03

Rendered for the player

The result becomes local text, sound, a menu, a marker or a vanilla outline. It does not alter server gameplay state.

Concept test — not a compatibility guarantee.

Unified Settings and Unified HUD Editing are default-off experimental tools.

The website and the mod have different boundaries.

qcloudy.net may read the public GitHub Release metadata needed for the download page. The installed Minecraft mod does not include that website code or perform that request.

03 / 05

VISIBLE, PLAYER-REQUESTED ACTIONS

Nothing is sent silently.

The following actions exist for convenience, but each one requires a direct player click or command. None runs on a timer or in the background.

/th

Warp to Torrhus

Sends exactly warp torrhus.

/helia

Open Torrhus Chapter

Sends exactly chapter torrhus.

Cake link

Visit for Century Cakes

The underlined chat link sends /visit northwestcloudy only after it is clicked.

Reconnect

One manual connection

The Reconnect button starts one normal connection after a click. There is no automatic retry loop.

Local-only commands

/qca, /qc, /qshard, /cake and /centurycakeeffect open local QCA interfaces and are not sent to the server.

04 / 05

OPTIONAL PROVIDERS

Integrates without taking ownership.

SkyHanni, Skyblocker, Firmament, BabyZombieAddons and Feesh are optional. QCA starts without them and exposes only recognized controls from installed builds.

OPT-IN

Separate master switches

Unified Settings and Unified HUD Editing are separate, default-off features with independent scans and results.

LOCAL

Deterministic discovery

Known paths and bounded local classification identify compatible controls. Refresh is manual and scanning requires confirmation.

FAIL CLOSED

Unknown stays untouched

If QCA cannot safely read or save a control, it is reported as unavailable instead of being guessed or modified.
