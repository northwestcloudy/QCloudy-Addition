# QCloudy_Addition 0.3.9 Release

适用于 Minecraft 26.1.2 与 26.2 的稳定 Release，汇总稳定版 2.5.3 之后的全部变化。

> **注意：**统一设置编辑与统一 HUD 编辑是实验性概念测试，默认关闭且尚不稳定。请备份第三方模组配置，并在对应模组原生编辑器中核对结果。

## 新增

- 完整离线 320-Shard 指南与多步 Fusion 规划器，包含配方、用途、候选路线、Materials Only、Ironman、可选提供方缓存价格、获取速度、Fusion Lines 与 Hunting Box 数量。
- 本地水钓/岩浆钓鱼 Ciallo 上钩提示音。
- Power Orb 与 Flare 消失提醒，并修正重新放置后的计时。
- 全部 20 种 Century Cake 的计时、效果菜单、合并过期提醒与仅点击执行的续效果操作。
- 面向五类提供方的可选按能力统一设置/HUD 探测。
- Minecraft 26.1.2 与 26.2 独立构建。

## 优化与修复

- Dwarven Mines 改为连续、近似、只使用 X/Z 的指针。
- 优化 Shard 与设置页面的自适应布局、点击区域、焦点和语义颜色。
- 修复 Tree Gift、Park Jungle 错误挖矿 HUD、Golden/Jade Dragon 等级、钓鱼重复音效、Century Cake 解析、SOS 替换计时及多处裁剪/重叠问题。

## 删除

- 槽位锁定、Storage Overlay 与菜单中键转换。
- `/aca` 与 `/ca` 命令别名。
- 旧 Dwarven Y/分区跳转、不完整的 Flare 距离/实体猜测与精确提供方版本白名单。

需要 Java 25、Fabric Loader 0.19.3+，以及与你所选 Minecraft 版本匹配的 Fabric API。QCA 仅作用于客户端，不安装可选提供方模组也可运行。
