# QCloudy_Addition 0.3.9 Release

Stable Release for Minecraft 26.1.2 and 26.2, consolidating all changes since stable Release 2.5.3.

> **Caution:** Unified Settings Editor and Unified HUD Editor are experimental concept tests. They are disabled by default and are not yet stable. Back up provider configuration and verify changes in each provider's native editor.

## Added

- Complete offline 320-Shard guide and multi-step Fusion Planner, including Recipes, Uses, alternative routes, Materials Only, Ironman, optional provider-cached prices, acquisition rates, Fusion Lines, and Hunting Box counts.
- Fishing Ciallo bite cue for confirmed local water/lava hooks.
- Power Orb and Flare despawn alerts with corrected replacement timing.
- All-20 Century Cake timers, effects menu, grouped expiry alerts, and click-only renewal action.
- Optional capability-based unified settings/HUD discovery for five supported provider families.
- Separate Minecraft 26.1.2 and 26.2 builds.

## Improved and fixed

- Continuous approximate X/Z-only Dwarven Mines marker.
- Responsive Shard and settings layouts, visible-content hitboxes, focus handling, and semantic colours.
- Fixed Tree Gift alerts, wrong Mining HUD in Park Jungle, Golden/Jade Dragon level display, duplicate fishing sound, Century Cake parsing, SOS timer replacement, and multiple clipping/overlap issues.

## Removed

- Slot locking, Storage Overlay, and menu middle-click conversion.
- `/aca` and `/ca` aliases.
- Old Dwarven Y/region snapping, incomplete Flare range/entity guesses, and exact provider-version whitelisting.

Requires Java 25, Fabric Loader 0.19.3+, and the Fabric API build matching the selected Minecraft version. QCA is client-only and runs without optional provider mods.
