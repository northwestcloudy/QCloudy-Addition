# QCloudy_Addition 0.3.10 Beta

适用于 Minecraft 26.1.2 与 26.2 的纯客户端 Fabric 公开 Beta，包含稳定版 Release 0.3.9 之后完成的全部变化。

> **Beta 提示：**统一设置编辑与统一 HUD 编辑仍为默认关闭的实验性功能；请备份提供方配置，并在提供方原生编辑器中核对写入。

## 新增

- 可选 Spirit Mask、Bonzo's Mask 与 Phoenix 免死提示和冷却 HUD，全部默认关闭。
- 可选好友/白名单组队邀请自动接受与精确私信组队申请。
- Party Chat `!` 快速组队指令与默认开启的本地双斜杠组队指令。
- Warp、All Invite、转移、踢人、坐标、晋升、Stream、地牢与 Kuudra 别名，支持触发者范围、冷却与玩家名补全。
- 只追踪稳定 Release 且不会自动下载或安装的更新提醒。
- 启动器/HMCL 与 Mod Menu 的官网、下载、源代码和问题反馈链接。

## 修复与改进

- 修复升级版 Bonzo's Mask 免死识别。
- 修复自动接受所依赖的 `/friend list` 多页同步。
- 修复通用目录无法滚到底部，并让“兼容模组”默认收起。
- 为四个设置/白名单页面加入浏览器式可拖动滚动条。
- 删除误导性 HUD 设置、空设置页与废弃 Firmament 背包功能让渡残留。

需要 Java 25、Fabric Loader 0.19.3+ 与对应 Fabric API。只安装与你的 Minecraft 版本对应的可运行 JAR；不要安装 Sources JAR。
